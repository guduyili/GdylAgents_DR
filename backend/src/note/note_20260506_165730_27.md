# 任务 2: 应用场景

请将本轮新增信息补充到任务概览中：

## 本轮新增关键发现
1. **最适合Agent承担的任务具有清晰边界：多步骤、可规则化、输入波动但输出可验证**。Cabin（2026-04）指出，成功落地的Agent场景普遍满足三个条件：目标可精确定义、所需数据可访问且较干净、异常与升级路径可文档化。其本质不是“完全替代人工”，而是把人工从“全量处理”转为“异常审核”。这一定义可作为场景筛选标准。
2. **客户服务是当前最成熟的Agent落地方向，价值来自高频低复杂度请求自动闭环**。Sema4.ai给出企业一线数据：常规工单处理时间下降60-80%；PlanetaryLabour汇总案例显示，Klarna AI助手处理66%的聊天，相当于700名全职客服产能，平均解决时间从11分钟降至2分钟以内，且覆盖23个市场、35+语言。说明客服Agent最适合承担查询、退款、改地址、订单追踪、分流与上下文整合等任务。
3. **金融与合规是ROI最高的行业之一，原因在于‘高规则密度+高文档密度+高错误成本’**。Sema4.ai指出发票处理时间可缩短70-90%；Cabin强调金融机构将Agent用于文档抽取、风险预筛、客户沟通草拟、监管变化监测，通常把人工审核压缩到15-20%的异常样本。该类场景的核心价值是缩短close cycle、降低人工例外队列、提升审计可追溯性，而不是让Agent直接做最终审批。
4. **医疗Agent的最佳切入点不是临床决策，而是行政与文档工作流**。Cabin指出，临床文书、先验授权（prior auth）、患者通知与排班、编码与计费审核是已经在生产环境运行的成熟方向；Databusinesscentral补充，医疗行政自动化在prior authorization上可实现40-60%的时间节省。共同规律是：Agent负责资料组装、规则比对、草稿生成，医生或编码员保留签核权。
5. **横向共性场景正从‘单点自动化’升级为‘跨系统编排’，IT/运营/采购/法务将成为下一波增长点**。Sema4.ai与Databusinesscentral都强调Agent区别于传统RPA/聊天机器人的关键，在于可跨CRM、ERP、工单、知识库、财务、法务系统完成端到端流程；如IT服务台分诊、采购审批、合同审阅、员工入职、供应链调度等。Databusinesscentral给出MTTR可下降最高60%，销售外呼能力可提升3-5倍，表明Agent价值正从“提效”走向“流程重构”。

## 建议补充到任务概览的判断框架
- **优先级最高的场景画像**：高频、高重复、多系统跳转、需要一定判断但可回溯校验、容错成本中低、存在清晰升级路径。
- **短期最具代表性的行业落地**：客户服务、金融运营/合规、医疗行政、IT服务管理、销售运营。
- **不宜优先完全Agent化的任务**：高风险临床诊断、最终信贷审批、开放式战略决策、数据基础极差且流程未标准化的工作。
- **实施原则**：从单流程中的一个高价值环节切入，而不是一开始端到端“全自动”；采用human-in-the-loop、审计日志、异常分流、权限隔离与系统观测能力作为企业级上线前提。
