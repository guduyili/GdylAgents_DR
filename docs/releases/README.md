# 最小版本迭代记录

## 约定

完整规则以项目根目录 [AGENTS.md](../../AGENTS.md) 为准，以下为版本记录摘要。

每轮只交付一个可独立验收的改进：明确问题与范围 → 失败测试 → 最小实现 → 回归与审查 → `test.md` → Git 提交与标签。

- 使用 `codex/<版本>-<主题>` 开发分支；保留已有用户修改，按主题明确暂存文件。
- `v0.0.x` 为仓库迭代标签，Python/npm 包版本独立管理；当前不进行包发布。
- 每版保留简短设计、计划、测试记录、审查与总结；**test 文档必须记录实际结果、复现命令和未验证范围**。
- 全量回归有阻塞时记录失败与基线对照，不能将局部通过称为全量通过。
- 提交通过审查的改动，创建本地 annotated tag；推送或合并按后续明确要求执行。
- 后续版本从最近已验收提交继续，不混入多个未验证方向。

## 下一版本建议

优先修复并发任务完成通知被批量读取丢弃后主循环不结束的问题，先用固定事件顺序建立确定性回归。随后处理运行存储测试的配置隔离，再继续线程超时边界实验。每版保持单一根因和独立验收。
