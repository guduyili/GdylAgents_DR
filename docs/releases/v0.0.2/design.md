# v0.0.2 设计：事实核对基线

## 目标与授权

落实进阶计划的第一个最小实验：构造无关来源反例，修复摘要自匹配。用户已要求按主线开始小版本更新、编写 test 文档并使用 Git 管理。

## 方案比较

- 仅修正匹配条件：删除摘要自身作为匹配来源的分支，范围最小，采用。
- 重做来源分块和逐条证据关联：更完整，但会改变结果含义，另开版本。
- 使用模型核对语义：需要评估集、模型调用和预算，本轮后置。

## 行为与边界

术语只能在来源文本中匹配；沿用大小写不敏感、缺词阈值、评分及事件结构。规则通过只表示词项匹配满足条件。`matched_sources` 保留原有 URL 回退，不代表已验证的证据清单。

## 验收

固定支持来源通过；足够长摘要搭配无关来源不通过且返回缺词；部分缺词按原阈值处理；结果通过执行器事件送出。先证明新增测试在旧实现失败，再验证修复通过。

## 版本范围

`v0.0.2` 是本仓库本地 Git 迭代标签，不是 Python/npm 包发布；本轮不调整包版本和依赖锁文件。保留开发分支与本地提交，不自动推送。
