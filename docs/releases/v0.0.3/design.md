# v0.0.3 设计：测试替身接口对齐

## 目标

恢复被 `stop_event` 参数漂移阻断的流式测试。`StreamRunner` 始终传递该参数，而 6 个旧执行器替身不接受它。

## 方案

采用显式增加 `stop_event: Event | None = None`，对齐真实执行器。保留原执行逻辑和断言；3 个只检查事件元数据的用例补充工具事件存在性断言，避免错误路径假通过。

不采用 `**kwargs` 掩盖未来接口漂移，也不修改生产调用兼容过期替身。同步执行器没有此调用约定，本轮不改。

## 范围与验收

业务代码不变。5 个非并发测试文件应从 8 failed / 2 passed 恢复通过；第 6 个并发测试独立限时验证。不同根因的失败或停顿记录为后续工作，不削弱原断言。

项目规则另存于根目录 `AGENTS.md`，已按用户要求作为独立文档提交。
